# Number_i リリース応援Webアプリ 企画書

> 非公式ファンサイト / ドラフト v0.1

---

## 1. 概要

### 1.1 目的
Number_iの新作リリース時に、ファンが **気軽に・楽しく応援でき**、**必要な情報をすぐ手に入れられる** Webアプリを提供する。

### 1.2 コンセプト
- 「開けば今日やることがわかる」
- 「近くのお店と在庫がすぐわかる」
- 「みんなで応援している実感がある」

### 1.3 ターゲット
| 区分 | 想定ユーザー | 主なニーズ |
|---|---|---|
| メイン | 国内ファン（スマホ利用中心） | 購入先・在庫・応援方法を素早く知りたい |
| サブ | 応援初心者 | 何をすればチャートに反映されるか知りたい |
| サブ | 海外ファン | 海外からの配信・購入方法を知りたい |

### 1.4 参考サイト
- https://ni-shopcheck-4thsingle.web.app/

## 3. 画面構成

```
/                     トップ（カウントダウン・今日やること・主要リンク）
├── /cd               通販（CD 通販サイトへのリンク・特典比較）
├── /shops            お店（実店舗のマップ・一覧・在庫報告）
│   └── /shops/:id    店舗詳細（在庫履歴・SNS・コメント）
├── /campaigns        キャンペーン一覧・期限
├── /guide            応援ガイド
├── /schedule         出演・メディアカレンダー
├── /chat             ファン報告チャット
└── /about            サイトについて・免責事項・お問い合わせ
```

「通販」と「お店」は **どこで買うか** で分ける（2026-09-28 決定）。
- 通販（`/cd`）：ネットで買う場所。公式ストア・EC サイトへのリンクと、通販・実店舗の特典をまとめた比較表
- お店（`/shops`）：実店舗。場所・在庫を探す。店舗詳細にもその店の特典を表示する
- 通販サイトの特典を持たせるため、`links` に特典の列が必要（D1 スキーマ作成時に確認のうえ追加）

### 3.1 トップページのレイアウト（スマホ基準）
1. ヘッダー（サイト名）※メニューは片手で押せるよう、画面下の固定ナビ（ホーム / 通販 / お店 / キャンペーン / メニュー）に置く
2. リリース情報カード（ジャケット画像は公式リンクのみ、タイトル・発売日）
3. カウントダウン（発売日 / 集計締切 / 直近のキャンペーン締切）
4. 今日の応援チェックリスト
5. クイックリンク（聴く / 通販 / お店 / キャンペーン）※「聴く」はホーム内の配信・DL リンクへ移動する
6. 配信・DL リンク（ストリーミング / ダウンロード購入）
7. MV（YouTube 公式の埋め込み + 再生回数）
8. 新着在庫報告
9. フッター（非公式表記・免責事項）

※ 当初あった `/listen`（配信・DL リンク）と `/mv`（MV）のページは作らず、内容をホームに置く。MV の推移グラフ・節目予測はやらない（2026-09-28 決定）

## 4. デザインガイドライン

### 4.1 方針
- **白背景 + 可愛い色味**
- **見やすさ最優先**：情報の階層をはっきりさせ、ボタンは大きく押しやすく
- スマホファースト（片手操作を想定）

### 4.2 カラーパレット（案）
| 用途 | 色 | HEX |
|---|---|---|
| 背景 | ホワイト | `#FFFFFF` |
| サブ背景 | ほんのりピンク | `#FFF7FA` |
| メイン | ピンク | `#FF8FB1` |
| サブ1 | ラベンダー | `#B8A4F4` |
| サブ2 | ミント | `#8FD9C4` |
| アクセント | イエロー | `#FFD66B` |
| テキスト | ダークグレー | `#3A3A4A` |
| 補助テキスト | グレー | `#6E6E7E` |
| 在庫あり | イエロー | `#FFD66B` |
| 在庫なし | グレー | `#C4C4CC` |

※ 文字色と背景色のコントラスト比は WCAG AA（4.5:1）以上を確保する。淡い色は背景・装飾に使い、文字には使わない。淡い色や在庫色の上に文字を載せるときは `ink` を使う（白文字は 4.5:1 に届かない）。
※ 補助テキストは当初 `#8A8A99` だったが、白背景で 3.40:1 と基準を満たさないため `#6E6E7E`（白 5.01:1 / サブ背景 4.75:1）に変更した（2026-09-27）。

### 4.3 タイポグラフィ
- 見出し・本文とも：M PLUS 1p（2026-09-28 決定。当初案の Zen Maru Gothic + Noto Sans JP から変更）
- 数字（再生回数・カウントダウン）：大きく太く、等幅数字を使用

### 4.4 UIルール
- 角丸：カード 16px / ボタン 999px（ピル型）
- 余白：8pxグリッド
- タップ領域：最小 44×44px
- アイコン：線の細い丸みのあるアイコンで統一
- アニメーション：控えめ（カウントダウン・スタンプ獲得時のみ軽く動かす）

## 7. 外部連携・実装メモ

### 7.1 YouTube 再生回数
- YouTube Data API v3（`videos.list` の `statistics.viewCount`）を使用
- **APIキーはフロントに置かない**。Workersで取得してD1に保存し、フロントはWorkersのAPIから読む
- Cron Triggersで定期取得（例：10〜30分ごと）。クォータ消費量に注意

### 7.2 店舗・在庫データ
- 店舗在庫を公開するAPIは基本的にないため、**ファン報告ベース**
- 加盟店の網羅的な公式リストは入手しづらいため、**手動整備 + ユーザーからの追加申請**で運用
- 店舗データは管理用のスプレッドシートで編集し、D1へ反映する運用も検討

### 7.3 位置情報
- ブラウザの Geolocation API で現在地を取得
- 位置情報はサーバーに送らず、端末内で距離計算する（プライバシー配慮）
- 許可されなかった場合は都道府県選択で代替

### 7.4 通知
- Web Push（VAPID鍵）で実装
- **iPhoneはホーム画面に追加（PWA）しないと通知が届かない**ため、初回に案内画面を表示
- 通知タイミング例：締切の3日前 / 前日 / 当日朝

### 7.5 X投稿テンプレ
- `https://x.com/intent/post?text=...` で本文入りの投稿画面を開く

## 8. セキュリティ・モデレーション

- 在庫報告・チャットは **連投制限**（IP・端末単位のレート制限）
- **NGワードフィルター**
- **通報機能**：一定数の通報で自動非表示
- Cloudflare Turnstile でBot対策
- 個人情報（本名・連絡先など）の書き込みを禁止するルールを明記
- 管理者用の非表示・削除画面

## 9. 権利・運営ポリシー

- サイト内に **「非公式ファンサイト」** であることを明記
- 公式写真・ジャケット画像の転載はしない（公式リンク・公式埋め込みのみ）
- MVはYouTube公式の埋め込みプレーヤーを使用
- 応援ガイドでは、不自然なループ再生など規約違反や集計除外につながる行為を推奨しない
- チャート指標は変更されることがあるため、公式ページへのリンクを添えて定期的に見直す
- 利用規約・プライバシーポリシー・お問い合わせ窓口を用意
